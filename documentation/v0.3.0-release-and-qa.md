# GIS Intake Assistant v0.3.0 — Release and QA

Date: 2026-07-27

## Release scope

- Modularized the original Streamlit application.
- Added a permanently visible address-copy control.
- Centralized and revised the product tagline.
- Added cached source-name suggestions from verified URLs.
- Added optional manual-county fallback.
- Added address-scoped `Not useful` suppression.
- Added review and Restore/Undo for suppressed links.
- Replaced the deprecated Streamlit HTML component.
- Added jurisdiction-aware county/city/state source matching.
- Added optional Special Conditions Source Discovery.

## Google Sheet migration

The live `GIS Sources` grid was expanded from 9 to 11 columns. The following
headers were appended:

```text
city
jurisdiction_level
```

No existing header, row, column order, or worksheet tab was deleted or moved.
Legacy county rows remain valid. Blank jurisdiction levels are inferred as
county only when the row already has a county; unscoped rows remain `unknown`.

## Expected limitations

- Public geocoding and web discovery can be rate-limited or change over time.
- General discovery candidates still require user review; a matching search
  result is not automatically a verified source.
- Legacy blank-county rows without a city cannot be safely inferred and should
  be backfilled before they are reused.
- Special Conditions results are source leads, never parcel findings.
- Final zoning, setbacks, overlays, hazards, permitting, and environmental
  requirements must be confirmed in the linked official source.
